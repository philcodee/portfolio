# Policy Admin Platform — Site Map
Cover Whale · Q1 2024

---

## Dashboard

### KPI Counts
- **Policies In-Force** (Total Count) — feeds from Policies > In-Force
- **Renewals-60 / Renewals-30** (Total Count) — feeds from Policies > Renewals
- **Bindable Quotes** (Total Count) — feeds from Quotes > Bindable
- **Pending Cancellation** (Total Count) — feeds from Policies > Cancellations

---

## Policies

### In-Force `→ NOTIF`
- Show all active policies
- Endorsements count

### At-Risk `→ NOTIF`
- Show any policies with compliance or non-pay issue

### Renewals
- Show any policies 60 and 30 days out from expiration

### Cancellations `→ NOTIF`
- Show any policies with 'Pending Cancellation' status
  - NOC issuance date
  - Reason for NOC issuance
- Show any cancelled policies
  - Cancelled date
  - Reason for cancellation

---

## Quotes

### Bindable `→ NOTIF`
- Show all bindable quotes, including renewal quotes, and endorsement quotes
- Quotes should also be tagged by stage (examples):
  - Stage: New Business
  - Stage: Endorsement
  - Stage: Renewal

### Not Taken Up
- Show all quotes with 'Not Taken Up' status
- Reason for not taken up

### In Review `→ NOTIF`
- Show any quotes in underwriting review
  - Any quotes which enter this stage should trigger a system notification
  - Any quotes which exit this stage should trigger a system notification

---

## Submissions

### Pending
- Show all submissions with 'In progress' status (date created/date last worked on)

### Declined `→ NOTIF`
- Show all submissions which have been declined, including any declines generated by the 'Pre-Submission' form

---

## Messages

### Sent/Received `→ NOTIF`
- Agent can send/receive a message through one of the following channels:
  - 'Producer Comment' – general comments about a particular quote or policy i.e. broker has a clean record
  - 'Underwriting' – underwriting-specific queries would be sent this channel
  - 'Billing' – any issues regarding payment, commissions, etc.
  - 'Support' – issues with the platform itself, bugs, discrepancies
