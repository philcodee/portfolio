# Portfolio Audit — June 11, 2026

## Typography

### What's working
- `brutalist-css.css` is the single source of truth for the type scale and imports Caprasimo, Space Grotesk, and DM Sans via `@import` at line 1. All case study pages inherit this correctly.
- `p, li, blockquote, td` are globally set to Space Grotesk at 1.2rem, which keeps body copy consistent across pages.
- Lifecycle popup text is correctly overridden at component level (0.95rem) and doesn't fight the global rule.

### Issues

**Inter is only loaded on `platform-architecture.html`**
The CW status chips use `font-family: 'Inter'`. Inter is loaded via `<link>` tags at the top of `platform-architecture.html`, but it's not in the `brutalist-css.css` @import. If chips or CW-system patterns appear in other case study pages, Inter will silently fall back to system sans-serif.
- **Fix:** Add Inter to the `@import` in `brutalist-css.css`, or load it in the site-wide `<head>` of every page.

**DM Sans is imported but unused**
The `@import` at line 1 of `brutalist-css.css` loads Caprasimo, DM Sans, and Space Grotesk. DM Sans doesn't appear to be applied anywhere.
- **Fix:** Remove it from the import to reduce the font payload.

**Caprasimo fallback is inconsistent**
Globally, headings fall back to `ui-monospace, monospace`. The `.next-link` in `platform-architecture.html` uses `font-family: 'Caprasimo', serif`. Minor, but serif is a worse fallback than monospace for this design system.
- **Fix:** Change `.next-link` fallback to `'Caprasimo', ui-monospace, monospace`.

**Body copy at 1.2rem is large**
The `p` rule at 1.2rem is noticeably large, especially next to `entry-label` elements and inside tight panel layouts. Worth pressure-testing across case study pages at both desktop and mobile widths to confirm it reads as intended rather than just big.

**`h2` has a hardcoded left border by default**
`h2 { border-left: var(--border-heavy); padding-left: 0.75rem; }` is the global rule. Several places override this inline (`border-left: none; padding-left: 0`) — particularly in hero sections and the next-link. These overrides work but are scattered.
- **Fix:** Create a modifier class (`.h2--flush`) so overrides are semantic rather than repeated inline styles.

**Working files are mixed with live content**
`agents/`, `build/`, and `logs/` are planning and process artifacts — not deployed content. They'll be included in any zip, git push, or deploy and add noise.
- **Fix:** Move them to a `_working/` folder at the repo root and add it to `.gitignore`. Or move them entirely outside the portfolio directory.

**Conversation logs inside `civic-guide-case-study/conversations/`**
There are 12 session log `.md` files inside a live case study folder. Same issue as above.
- **Fix:** Move to `_working/civic-guide/`.

**Orphaned docs inside case study folders**
- `platform-architecture/lifecycle-diagram-prompt.md` — a prompt file inside a live case study
- `civic-guide-case-study/asset-map.md`, `building-civic-trust-findings.md`, `carbon-css-revision-guide.md`
- `policy-admin/reference/ia-rationale.md`, `site-map.md`

These are reference docs that belong in `_working/`, not alongside the HTML.

**Icon filenames in `platform-architecture/icons/`**
Two icons have mangled names from duplicate downloads:
- `receipt_long_FILL0_wght300_GRAD0_opsz24 (1) 1.svg`
- `shield_FILL0_wght300_GRAD0_opsz24 (1) 1.svg`

There's also a nested subfolder with a space in its name: `icons/Interface, Essential/menu-burger.svg`.
- **Fix:** Rename icons to short, clean names (`receipt.svg`, `shield.svg`, `menu.svg`) and flatten the subfolder. Update any references in `search-filter-demo.html`.

**`timer/timer/` nested folder**
The actual Python app (`timer_app.py`, `timer_web.py`, `fiducial_sdk.py`) is nested inside `timer/timer/`. It's source code for the project, not portfolio assets — it probably doesn't need to live inside the deployed portfolio at all.

**`policy-admin/policy-admin.csv`**
A raw CSV in a live case study folder. Likely a data reference or test file.
- **Fix:** Move to `_working/` or delete if no longer needed.
